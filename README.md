# Jerry - Worldbuilding Website

Authors: Shivesh Dunddumalla, Owen Hayes and Abhi Ramachandran

Welcome to Jerry! This is a worldbuilding website written ENTIRELY in Vanilla JS where you can create the alternate history that YOU want.

## Tech Stack

- Vanilla JS
- HTML
- CSS
- NodeJS
- Express
- PostgreSQL

## How to Run

### Database

1. Create database if it doesn't exist:

   ```bash
   createdb jerry
   ```

2. Copy the env file and set the database URL:

   ```bash
   cp .env.example .env
   ```
